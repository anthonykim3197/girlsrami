# 걸스라미 자사몰

운영 주소는 https://girlslami.com 입니다. GitHub `anthonykim3197/girlsrami`와 연결된 Cloudflare Pages에서 정적 HTML/CSS/JavaScript를 제공하며, 결제는 각 상품의 검증된 네이버 스마트스토어 페이지로 연결합니다.

## 2026-10-16 출시 범위

이번 릴리스는 기존 판매 12종을 보존하고 신규 9종을 더해 **21개 상품, 155개 판매색, 620개 색상별 코디 이미지**를 제공하는 구성을 목표로 합니다. 신규 품번은 JO23·JO24·JO31·JO32·RM542·RM543·RM567·RM576·RM582이며, 모두 스마트스토어 `SALE` 상태와 공개 구매 URL을 확인했습니다. 상품별 URL과 출시 근거는 [`docs/NEW9-LAUNCH-20261016.md`](docs/NEW9-LAUNCH-20261016.md)에 정리했습니다.

상세페이지의 공통 인터랙티브 기준은 다음과 같습니다.

- 판매색마다 A·B·C·D 네 가지 코디
- 판매색마다 모델 8방향과 제품 단독 8방향 회전 보기
- 색상 팔레트, 원단 전체·접사, 촬영 원본, 이미지 확대
- 검증된 FREE 사이즈와 cm 단위 실측

신규 9종은 각 10색, 4코디로 구성합니다. 판매색은 아이보리·검정·브라운·연핑크·카키·차콜·곤색·보라·연밤·그레이입니다. 제품정보의 원본 색상 목록에는 오트밀도 있으나 실물 색상 참조가 확보되지 않아 이번 판매 옵션과 색상 이미지에서 제외했습니다.

`NEW` 표시는 이번 신규 9종과 앞서 점주가 신규 디자인으로 확인한 RM382·RM495에 적용합니다. 스마트스토어 등록 시점이나 상세페이지 제작 시점만으로 신규 디자인 여부를 바꾸지 않습니다.

## 빌드와 검증

```bash
npm run build
npm run test:storefront
```

`npm run build`는 공개 파일을 `dist/`에 복사하고 활성 판매 상품의 정적 상세페이지와 sitemap을 생성합니다. `assets/detail/`을 재귀 복사하며 파일 크기와 누락된 로컬 참조를 검사합니다. 촬영 작업 폴더, 테스트 자료와 비밀값은 배포하지 않습니다.

`npm run test:storefront`는 공개 상품 수와 미디어 범위, 상세 콘텐츠, 검색 정보, 내비게이션, 이미지 레이아웃과 회전 동작을 검사합니다. 이번 출시의 최종 빌드·테스트·배포 결과는 실행 후 별도 배포 기록에 남깁니다.

## 주요 파일

- `data.js`: 공개 상품 목록과 판매 상태
- `detail-catalog.js`: 상품별 카피, 코디, 색상, 촬영 원본, 팔레트, 원단과 회전 미디어
- `standard-detail.js`, `standard-detail.css`: 확대·색상·코디·회전 동작을 포함한 공통 상세페이지
- `app.js`, `catalog.css`: 홈·목록·상품 카드와 공통 화면
- `seo-products.json`, `scripts/build.mjs`: 판매 상품의 정적 검색 정보와 페이지 생성
- `member.js`: 기존 회원·관리·장바구니 기능. 운영 상품은 Supabase에서 읽습니다.
- `docs/STOREFRONT-CONTENT-STANDARD.md`: 썸네일·카피·이미지·실측 제작 기준
- `docs/NEW9-LAUNCH-20261016.md`: 신규 9종의 판매 등록, 색상, 수량 의미와 원본 근거

## 출시 순서와 데이터 기준

신규 9종은 정적 자산과 카탈로그를 먼저 배포한 뒤, Supabase의 기존 v3 초안을 갱신하고 게시합니다. 이 순서를 지켜 DB가 아직 공개되지 않은 정적 경로를 참조하지 않게 합니다. 기존 12종의 레코드와 상세 데이터는 신규 9종을 설치할 때 보존해야 합니다.

신규 상품의 옵션 수량 `1000`은 색상별 판매 시스템 설정값이며 실제 창고 재고를 뜻하지 않습니다. 10색 합계 `10000`도 같은 설정값의 합계입니다. 실제 구매 가능 여부, 배송과 결제 조건은 스마트스토어의 현재 상품 페이지를 기준으로 합니다.

촬영 사진의 그레이카드는 화이트밸런스와 색 편향을 상대적으로 판단하는 참조입니다. 18% 노출 카드 여부와 측색 장비의 정확도는 확인되지 않았으므로, 화면의 색상값을 실험실 측색 결과로 설명하지 않습니다.

## 검색 및 오류 페이지

가상 F/W 상품은 공개 목록과 sitemap에 포함하지 않습니다. 루트 `404.html`은 없는 URL을 홈 화면으로 반환하던 Cloudflare Pages의 SPA fallback을 방지합니다. 삭제한 이미지도 실제 404로 응답해야 합니다. 관련 점검 경로는 `docs/LEGACY-IMAGE-404-CHECK-20261015.md`에 정리했습니다.
