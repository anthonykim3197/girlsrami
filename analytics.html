상품 관리
최종 주문 · 매출은 확인 불가

스마트스토어 주문 데이터가 연결되지 않았습니다. 구매 버튼 클릭과 외부 이동은 결제 완료가 아니며, 브라우저 세션 수도 실제 사람 수를 뜻하지 않습니다.

관리자 계정으로 로그인하면 사이트 전체 집계를 볼 수 있어요.

관리자 로그인

구매 버튼 클릭은 스마트스토어 이동에도 포함됩니다. 두 수치를 더하지 마세요. 차단·자동화·중복 탭과 30분 세션 만료의 영향을 받습니다.

상품별 행동

유입 경로

세션 첫 진입의 도메인과 UTM 코드입니다. 전체 주소·검색어는 저장하지 않습니다. 비어 있으면 직접 유입 또는 확인 불가입니다.

MEASUREMENT CHECK

이 탭에서 동작 확인

확인 모드에서는 이벤트를 이 탭에만 저장하고 운영 통계로 보내지 않습니다. 상품에서 색상·사이즈·구매 버튼을 누른 뒤 이 화면으로 돌아오세요.
