# 걸스라미 자사몰 상품 콘텐츠 기준

기준일: 2026-10-16 · 적용 범위: 자사몰 상품 목록·검색 카드·상품 상세페이지

이 문서는 상품마다 달라졌던 썸네일, 소개 문구, 상세페이지 순서와 표기 방식을 통일하는 제작 기준이다. 오프듀티 V넥 니트 베스트(RM495)를 첫 적용 예시로 삼고, 이후 기존 상품과 신상품에도 같은 원칙을 적용한다. 상품마다 사진과 문구는 달라져도 정보의 위치와 사용 방식은 같아야 한다.

**핵심:** 목록에서는 입술·턱선에서 크롭한 자연스러운 거리 착장으로 옷을 돋보이게 하고, 상세페이지에서는 입고 싶은 이유 → 코디 → 색상 → 실물 디테일 → 사이즈 순서로 구매 판단을 돕는다.

시안 제작과 게시 승인은 별개다. **완성한 PC·모바일 시안에 대한 점주의 명시적인 승인 전에는 운영 자사몰·스마트스토어에 게시하지 않는다.** 이 문서는 게시 승인을 대신하지 않는다. 2026-10-15 점주는 완성된 자사몰 상세 구성을 기존 판매 상품 전체에 적용하도록 요청했다. 이번 적용 범위는 실제 판매 12종이며, 신규 9종의 스마트스토어 등록이나 공개 판매는 포함하지 않는다.

## 1. 모든 상품에 고정할 구성

| 위치 | 표시할 내용 | 기준 |
|---|---|---|
| 상품 카드 | 대표 착장, 필요한 경우 `NEW`, 상품명, 짧은 소개, 가격 | 입술·턱선에서 잘라 얼굴 전체를 드러내지 않고 판매 의류 전체가 보여야 한다. 혼용률·긴 정보 문구는 카드에서 제외한다. |
| 구매 영역 | 대표 착장, 상품명, 소개 1문장, 가격, 색상·사이즈 선택, 구매 기능 | 색상 선택기는 유지한다. 중복되는 별도 판매 색상 소개와 가까운 섹션으로 이동하는 장식용 링크는 넣지 않는다. |
| Intro | 상품명과 제품의 매력을 전하는 짧은 글 | 치수를 나열하지 않는다. 동일한 대표 사진을 바로 아래 다시 크게 반복하지 않는다. |
| Styling | 모든 판매 색상에 상품별 착장 4종 | 대표 착장은 구매 영역과 공유할 수 있으나 본문에 같은 이미지를 연속해서 중복 배치하지 않는다. |
| Color Palette | 해당 상품의 실제 판매·생산 가능 색상 전체를 담은 스튜디오 구성 컷 | 본문에서 한 번만 보여주고 실제 배열 순서대로 색상명을 표시한다. |
| Fabric Detail | 원본 기반 스튜디오 전체 컷 + 원단·마감 확대 컷 | 마네킹·옷걸이·주변 소품을 드러내지 않는다. 촬영 원본은 접어서 확인할 수 있게 보존한다. |
| Size Guide | 번호를 표시한 옷 도식과 대응 실측표, 기본 상품 정보 | 한눈에 비교할 수 있도록 구성한다. 미확인 수치를 채우지 않는다. |
| Care & Info | 확인된 세탁·관리 정보와 필요한 구매 안내 | 반복 설명은 정리하고 공통 배송·교환 안내와 역할을 나눈다. |
| Reviews | 확인된 구매 후기 또는 후기 작성 안내 | 수집되지 않은 후기를 만들어 채우지 않는다. |
| Related | 함께 보면 좋은 판매 상품 | 현재 구매 가능한 다른 상품을 연결한다. |
| 상세페이지 최하단 | AI 연출 안내 한 문장 | 읽을 수 있는 크기와 대비로 한 번만 표시한다. |

360도 보기·원본 확대 등 자사몰 기능은 관련 사진 영역 안에 둔다. 기능을 넣기 위해 동일한 사진 묶음이나 제목을 또 만들지 않는다. 촬영된 각도만 사용하고 실제로 없는 각도를 실물 사진처럼 보충하지 않는다.

## 2. 썸네일과 NEW 표시

### 대표 사진 선택

- 2026-10-16 점주 요청에 따라 기존 얼굴 노출 기준을 변경한다. **입술·턱선에서 크롭한 거리 화보**가 목록의 기본 구도다. 눈과 코를 드러내지 않고 옷이 주인공이 되게 한다.
- 자연광, 거리·카페·건물 배경, 자연스러운 자세를 사용한다. 배경과 코디를 상품마다 조금씩 달리하되 브랜드 모델과 실제 의류의 색·핏·넥라인·짜임을 유지한다.
- 어깨·품·소매·밑단이 모두 보이도록 입술선부터 골반~허벅지 상단까지 담는다. 옷의 길이·품을 줄이거나 늘려 크롭에 맞추지 않는다.
- 카드 영역은 **3:4**다. 사진마다 구도를 확인하고 PC·모바일에서 의류가 잘리지 않는지 검수한다. 원본을 크게 늘려서 흐려지게 하지 않는다.
- `detail-catalog.js`의 `cardThumbnail`은 목록·홈·추천 카드와 OG/Product 검색 이미지에 사용한다. `thumbnail`과 `looks`는 상세 전신 착장용으로 보존한다. 카드 크롭 때문에 상세 코디나 360 자료를 덮어쓰지 않는다.
- 웹 배포본은 고화질 WebP로 인코딩하고 생성 원본·프롬프트·참조 사진은 작업 폴더에 별도 보관한다. 의류의 색·재질·실측을 임의로 보충하지 않는다.
- 자사몰 고객용 상품명에는 선두 `걸스라미`를 붙이지 않는다. 사이트 로고, 문서 제목 뒤 브랜드, 제조사·브랜드 정보는 유지한다.

### 배지

- `신상` 대신 **`NEW`**를 쓴다. 큰 적갈색 블록, 과한 둥근 모서리, 두꺼운 글씨를 피한다.
- 권장 모양: 작은 차콜 바탕에 흰색 글씨 또는 아이보리 바탕에 진한 글씨, 가는 테두리. 글자 10~12px, 가벼운 자간, 얕은 모서리, 사진 가장자리 안쪽 12~16px.
- 배지는 얼굴이나 네크라인을 가리지 않는 위치에 둔다.
- 신상품 여부는 **점주가 지정한 신규 디자인 분류를 우선**하고 디자인별 등록·판매 이력으로 대조한다. SmartStore에 이미 등록됐다는 이유만으로 `NEW`를 해제하지 않는다. 운영 12종 중 점주가 신규 9종보다 앞서 추가한 **허니루프 RM382·오프듀티 RM495는 NEW**, 나머지 10종은 제외한다. 사진·페이지를 새로 만들었다는 사실만으로 신상품을 추가하지 않는다. 근거 등록부는 [상세 미디어 범위](STOREFRONT-DETAIL-COVERAGE-20261015.md)의 NEW 분류 표를 따른다.
- 배지·가격·상품명은 가능한 한 HTML로 표시한다. 사진 자체에 문구를 굽지 않는다.

## 3. 구매하고 싶어지는 문장 작성법

좋은 소개는 **눈에 보이는 제품 특징 하나와 입는 장면 하나**를 연결한다. 자연스러운 감성 표현은 사용하되, 의미 없이 분위기만 반복하거나 검증되지 않은 성능을 약속하지 않는다.

| 용도 | 분량과 방식 |
|---|---|
| 상품 카드 소개 | 1문장. 상품명의 되풀이와 혼용률 나열을 피한다. |
| 구매 영역 소개 | 1문장. 사진을 보고 느낄 제품의 매력을 구체화한다. |
| Intro 제목 | 1~2줄. 제품명과 똑같은 제목을 또 쓰지 않는다. |
| Intro 본문 | 2~4문장. 특징 → 입는 방법 → 선택할 이유 순서로 쓴다. |
| 착장 설명 | 조합의 차이를 보여주는 1~2문장. 모든 소품을 목록처럼 반복할 필요는 없다. |
| 디테일 설명 | 사진에서 확인되는 짜임·마감·형태를 한 문장으로 설명한다. |

**피할 문장**

- 소개를 `V넥, 총장 46cm, 가슴 단면 55cm`처럼 실측표로 만드는 문장.
- `당신의 일상을 완성하는`, `감각적인 무드`, `완벽한 실루엣`처럼 상품을 바꿔도 그대로 붙일 수 있는 말의 반복.
- 근거 없는 `까슬거림 제로`, `보풀 없음`, `체형 완벽 커버`, `누구나 잘 맞는`, `최고급`, `품절 걱정 없는`, `배송 보장`.
- 측정하지 않은 `가볍다`, 착용으로 확인하지 않은 `부드럽다·따뜻하다·편하다`를 사실처럼 단정하는 표현.
- 연령대를 정해서 고객을 좁히는 `4050을 위한`, `중년 여성 필수` 등의 소개.
- 경쟁몰 문구의 복사 또는 어순만 바꾸기. 참고하는 것은 정보의 배치와 읽히는 방식이다.

### RM495 적용 문구 예시

**카드·구매 영역 소개**

> 흰 티에도 셔츠에도, 입체적인 짜임으로 달라지는 레이어드.

**Intro 제목**

> 늘 입던 조합에, 니트 한 겹.

**Intro 본문**

> 흰 티와 데님만 입기엔 조금 심심한 날, 오프듀티를 더해 보세요. V넥 사이로 이너가 드러나고, 입체적인 짜임이 단순한 조합에 표정을 더해줘요. 셔츠의 칼라와 소맷단을 살리면 또 다른 느낌. 데님부터 롱스커트까지, 옷장 속 익숙한 옷들과 먼저 매치해 보세요.

**Styling 예시**

- **Weekend Denim** — 흰 티와 밝은 데님에 스카이 베스트. 스니커즈로 마무리하면 가볍게 외출하기 좋은 조합이에요.
- **Shirt & Skirt** — 카멜 베스트 아래로 흰 셔츠의 칼라와 소매를 살려보세요. 긴 아이보리 스커트와 플랫을 더하면 차분하게 입기 좋아요.

**Fabric Detail 예시**

> 입체적인 몸판 짜임에, V넥과 밑단은 골지로 마무리했어요.

위 문구는 현재 확보된 사진과 확인된 형태를 기반으로 한 예시다. 다른 상품에 상품명만 바꿔 재사용하지 않는다. `가볍게 외출`은 코디 장면이며 제품 중량 설명이 아니다.

## 4. 섹션 명칭과 중복 제거

| 기존 표현·구성 | 통일할 표현·구성 |
|---|---|
| `AI 코디`, `AI STYLING`, `AI 코디 1` | **Styling** 또는 **Style 01 / Style 02** |
| 각 사진의 `AI 코디 · 회색` 배지 | 필요한 경우 **Gray / 회색**처럼 색상만 간결하게 표시 |
| `실제 짜임과 상품 정보` | **Fabric Detail** |
| `상품 실측` | **Size Guide** |
| `판매 색상`, `SALE COLORS` | **Color Palette** |
| 큰 수치 카드의 연속 | 번호 도식 + 간결한 실측표 |
| `나의 코디 찾아보기 ↗` | 삭제. 바로 아래 Styling으로 이동하는 링크를 따로 만들지 않음 |
| 구매 영역 아래 색상 연출 + 본문 색상 소개 | 상단 편집용 색상 연출을 삭제하고 본문 Color Palette 한 곳만 유지 |
| 사진마다 반복되는 AI 안내 | 상세페이지 최하단의 공통 안내 한 번으로 통합 |

구매 영역의 **색상 선택기**는 주문에 필요한 기능이므로 유지한다. 중복 제거 대상은 편집용 색상 소개·연출 이미지 묶음이다. 사이즈 가이드 버튼처럼 구매 결정을 돕는 링크는 유지할 수 있다.

## 5. 색상·실물 사진·생성 이미지 기준

- 판매 또는 생산 가능한 색상은 **각 상품의 정보 원문과 확인 기록**을 기준으로 한다. 공용 asset 폴더에 있는 색상을 모든 상품의 옵션으로 자동 확장하지 않는다.
- 공용 니트 샘플은 색 참고용이다. 다른 디자인의 샘플을 해당 판매 상품 실물로 표시하지 않는다.
- 촬영 조건·그레이카드 참조·색 보정 이력을 보관한다. 이력이 확인되지 않으면 `그레이카드로 정확히 보정 완료`라고 쓰지 않는다.
- 추출한 HEX는 화면용 근사값이다. 모니터와 촬영 조건의 차이를 고려하며 실물 색과 완전히 동일하다고 약속하지 않는다.
- 2026-10-15 점주의 추가 지시: 기존 상품도 허니루프와 동일한 구성으로 통일하고 마네킹·옷걸이 상세컷은 바닥에 놓은 스튜디오 컷과 확대 사진처럼 정돈한다. **실제 상품 촬영 원본을 참조한 편집**만 사용하며 색상·짜임·단추·넥라인·소매·품·길이를 대조한다. 촬영 원본은 `fabricOriginals`에 남기고 고객이 `촬영 원본 확인`에서 확대할 수 있게 한다. 실제 원단 판단에 필요한 원본을 삭제하거나 생성 접사를 실물 원본으로 표시하지 않는다.
- 스튜디오 편집 이미지는 `mediaKind: studio-edit`, 실제 접사는 `mediaKind: photo`로 구분한다. 기존에 마네킹이나 소품이 없는 실제 접사는 보존한다. 한 상품의 Fabric Detail은 전체/형태 컷과 확대 컷 최소 2장으로 구성한다.
- 네 가지 코디의 모든 판매 색상에 별도 화보가 있어야 한다. 이미지가 없는 코디 버튼, 타 색상 대체, 동일 사진 네 번 재사용은 완료로 보지 않는다.
- 썸네일과 착장 이미지는 `실물`, `AI 생성`, `실물 사진 편집` 출처를 내부 데이터에 구분해서 보관한다. 사용자에게 같은 AI 배지를 반복 노출하지 않는다.

## 6. Size Guide 구성

### 번호 도식

- 실제 상품 형태를 반영한 단순 도식을 사용한다. 판매 옷이 베스트라면 소매가 있는 니트 도식을 쓰지 않는다.
- 화살표와 번호를 대응시킨다. 기본 항목은 총기장, 가슴 단면, 어깨, 목 너비, 앞목 깊이이며 상품별로 필요한 항목만 사용한다.
- 가슴 단면은 옷을 평평하게 놓고 양쪽 겨드랑이 바로 아래를 수평으로 잰 좌우 폭이다. 화살표 끝과 번호를 이 위치에 맞춘다. 둘레 전체를 뜻하는 곡선으로 표시하지 않는다. RM495는 점주가 이 측정 위치를 확인했으며 기존 55cm를 유지한다.

### 실측표

- PC는 표 머리글과 한 행의 수치를 쉽게 비교할 수 있게 배치한다. 모바일은 도식 다음에 번호·측정 부위·수치가 대응하는 세로 표 또는 좁은 화면용 표를 사용한다.
