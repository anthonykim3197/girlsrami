# 23상품 상세페이지 통일

2026-11-16, 승인된 JO27 시안을 자사몰의 공통 상세 구성으로 적용한다.

- 공개 판매 23상품, 판매색 171개, 색상별 4코디 총 684개를 유지한다.
- 소개 → 사진이 있는 Styling → 클릭형 Color Palette → 원본 기반 Product Detail → 실측 → Care & Info → 구매 후기·배송 안내.
- JO27은 승인된 생활 장면 화보 44장으로 교체한다. 다른 22상품은 기존 화보를 유지한다.
- 승인된 JO27·RM584·RM576·RM542·RM279 대표 썸네일 5장을 적용한다. 상세 화보와 목록용 눈 아래 크롭은 별도 자산이다.
- 제품 단독 사진은 실제 촬영 원본의 옷 RGB를 유지한 투명 PNG다. 마네킹·옷걸이·배경 및 비판매 코디 의류만 alpha mask로 제외했다. 새로운 옷 픽셀 생성·색 변경·원단 재구성은 없다.
- 공개 제품 보기와 확대는 누끼 사진을 사용한다. 원본 파일·색상·해시 자료는 출처 검증을 위해 카탈로그에 보존한다. 원본 배경 사진과 JO27 추정 후면은 상세에 노출하지 않는다.
- 실측, 가격, 옵션, 재고, 구매 링크와 DB를 변경하지 않는다. RM375·RM418의 미확정 혼용률은 추정하지 않는다.
- 실제 누끼와 원본 확대 이미지가 없는 상품은 빌드 검증을 통과할 수 없다. 색상 카드 클릭도 기존 옵션 선택 분석에 기록한다.

배포 전 기준 커밋은 `65449fed47d244de4423ef46d9a2dede38f7b0b2`다. 기존 Cloudflare Pages 성공 배포 `e1a1480b-388c-405f-b4e2-268b23d84d42`를 복구 기준으로 기록한다. 배포는 기존 `main` → Cloudflare Pages `npm run build` / `dist` 경로를 사용한다.

검증: `npm run build`, `npm run test:storefront`, `npm run test:admin`, `npm run test:analytics`, `npm run test:links` 및 운영 23상품의 이미지·색상·구매 링크·모바일 표시 확인.

## 배포 전 검증 결과

- 빌드 성공: 판매 23상품 / 출시 예정 0상품.
- 자동 테스트 156개 통과: storefront 123, admin 16, analytics 14, shopping links 3.
- 모바일 390px에서 23상품 모두 이미지 누락·가로 넘침 없음. 색상 팔레트 선택, 제품 보기, PNG 원본 확대, 정확한 구매 URL 확인.
- 원본 기반 제품 사진 25장·확대 컷 46장. 신규 22개 정면 PNG의 디코딩 후 불투명 RGB 차이 0, 원본 프로필 유지, 합성 픽셀 0. JO27 3각도는 기존 승인 검증본 재사용.
- 브라우저 자동 검수는 서버 렌더 이미지의 표시뿐 아니라 갤러리 이벤트 연결 완료까지 기다려 실행했다.
