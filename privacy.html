선택 서비스: 내 사진 피팅

사진 생성은 별도의 동의를 받은 본인 사진과 실제 상품 사진만 사용합니다. 사진을 고르기만 하면 서버로 전송되지 않습니다. 생성 요청 전에 브라우저에서 사진의 촬영 메타데이터를 제거합니다.

  • 목적: 선택한 니트를 입은 코디 참고 이미지 생성. 체형 진단이나 실제 핏 보장은 제공하지 않습니다.
  • 항목: 본인 사진, 선택한 상품·색상, 생성 결과와 동의 기록. 신체 치수는 GPU에 전달하지 않습니다.
  • 저장: Supabase 비공개 저장소, 대한민국 서울 지역(ap-northeast-2). 회원 본인과 생성 처리 시스템만 접근합니다. 일반 상품 관리자는 사진과 치수를 열람할 수 없습니다.
  • 처리: 대한민국에 설치된 걸스라미 전용 GPU 서버에서 FLUX.2 klein 4B 모델로 추론하도록 준비 중입니다. 사진은 서버 메모리에서 처리하며 GPU 서버의 파일로 저장하지 않습니다. 이 처리 경로에는 Google Colab이나 Google 이미지 API를 사용하지 않습니다. 기존 코랩 처리 동의와 구분해 사진 전송 전에 새 동의를 받습니다. 자동 삭제와 회원 사진 생성 시험을 확인한 후 서비스를 제공합니다.
  • 보관: 원본과 결과는 24시간 동안만 열람할 수 있도록 제한합니다. 자동 삭제 작업의 작동을 확인한 후 서비스를 제공합니다. 내 정보의 삭제 버튼으로 삭제를 요청하면 진행 중 생성도 취소됩니다. 삭제에 실패하면 화면에서 알리고 다시 요청할 수 있습니다.
  • 요청 기록: 사진 삭제 후에도 중복 요청 방지·일일 생성 한도 적용에 필요한 요청 ID와 계정 ID, 처리 시각을 최대 24시간 보관합니다. 이 기록에는 사진이나 신체 치수를 저장하지 않습니다.
  • 동의 철회: 내 정보 → 사진 삭제 · 동의 철회. 사진 피팅 동의를 거부하거나 철회해도 회원·상품 조회·구매 서비스를 이용할 수 있습니다.
  • 회원 사진과 결과를 모델 학습, 광고 또는 공개 상품 이미지로 사용하지 않습니다.

외부 서비스와 브라우저 저장

회원 인증·데이터 저장에는 Supabase 서울 지역, 사이트 제공에는 Cloudflare Pages를 사용합니다. 가입 확인·비밀번호 재설정 메일을 연결하기 위해 Resend의 일본 도쿄 지역(ap-northeast-1)에 인증용 발송 도메인을 등록했습니다. 메일 설정이 활성화되면 수신 이메일 주소와 인증 메일 내용이 해당 발송 서비스에 전달됩니다. 신체 치수와 사진은 메일에 포함하지 않습니다. 로그인 유지에는 인증 토큰을 브라우저에 저장합니다. 공용 기기에서는 이용 후 로그아웃해 주세요.
